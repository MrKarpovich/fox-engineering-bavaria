# 🦊 Лисёнок из Минска — SSH Unlocker для BMW NBT EVO

Простая программа для разблокировки SSH (и telnet/qconn) на **BMW NBT EVO**.

Одна большая кнопка — программа сама находит голову, проверяет себя и открывает SSH.

## Требования

- Windows 10 / 11
- ENET-кабель (OBD → Ethernet)
- Ноутбук с возможностью получать адрес `169.254.x.x`
- ГУ NBT EVO id 5/6 (семейство 007.xxx)

## Подготовка компьютера (обязательно)

Перед запуском сделайте следующее:

1. **Электропитание**
   - Схема управления: **Высокая производительность**
   - Закрытие крышки: **Ничего не делать**
   - Переход в спящий режим: **Никогда**
   - Отключение дисплея: **Никогда**

2. **Защитник Windows**
   - Параметры защиты от вирусов и угроз → Управление настройками
   - Отключите **все** пункты защиты в реальном времени

3. **Брандмауэр Windows**
   - Полностью выключите брандмауэр (для частных и общественных сетей)

4. **Сетевой адаптер**
   - Параметры IPv4 → **Получать IP-адрес автоматически**
   - Получать адрес DNS-сервера автоматически

## Порядок действий в машине

1. Пристегните ремень безопасности  
2. Заведите машину **с нажатой педалью тормоза**  
3. Подключите ENET-кабель к диагностическому разъёму  
4. Подключите ноутбук к кабелю  
5. Убедитесь, что адаптер получил адрес вида `169.254.x.x`

---

## Запуск программы

1. Запустите файл **`Lisenok_SSH_Unlocker.exe` от имени администратора**  
   (правой кнопкой → Запуск от имени администратора)

2. Нажмите большую оранжевую кнопку **«НАЧАТЬ — Разблокировать SSH»**

3. Подтвердите действие, введя слово `fox`

4. **Ничего не трогайте** до конца процесса  
   - Не закрывайте программу  
   - Не отключайте кабель  
   - Не выключайте машину  
   - Не переводите ноутбук в сон  

5. Дождитесь зелёного сообщения **«SSH успешно разблокирован!»**  
   Процесс может занимать **до 10 минут**.

6. После успешного сообщения подождите ещё **40–60 секунд**, пока ГУ полностью перезагрузится.
