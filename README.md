### 📌 What is this?

This is my personal collection of **open-source tools for BMW diagnostics, coding, and data management** — built with care, tested in real life, and shared with the community.

All tools are:
- ✅ Standalone `.exe` (no Python needed)
- ✅ No external dependencies (pure standard libraries)
- ✅ GUI-based — easy for everyone
- ✅ MIT licensed — use, modify, share freely

---

### 🧰 Tools

#### 1. 🦊 [ISTA RegFox](./ISTA-RegFox)  
Windows Registry manager for **BMW ISTA/Rheingold**.  
Safely activate/deactivate programming mode, auto-backup registry states, and restore anytime.

> ℹ️ *"From time to time, we run technical campaigns to address even the slightest possibilities that may disrupt your driving pleasure."*  
> — [BMW Malaysia](https://www.bmw.com.my/en/topics/bmw-owners/bmw-aftersales-services/technical-campaign.html)

> ⚠️ **Warning**: Modifies Windows Registry. Use at your own risk.

---

#### 2. 🔄 [PSDZData Incremental Updater](./PSDZData-Updater)  
Stop re-downloading **300 GB** of `psdzdata`!  
This tool compares two versions and creates a **minimal update** with only changed files.

- SHA-256 verified
- Works as .exe — no Python required
- Share `.json` snapshots with the community!

---

#### 3. 🦊 [FoxRecalls](./foxrecalls)  
Check your BMW for active recalls & technical campaigns.

- 🇪🇺 **BMW EU** 
- 🇺🇸 **BMW USA** 
- Send defect codes → get instant descriptions  
- Telegram bot: [@FoxRecallsBot](https://t.me/FoxRecallsBot)  
- Desktop app (coming soon)

> ⚠️ **Note**: The EU portal is **not applicable to imported used cars**.

### 🧰 Инструменты

#### 1. 🦊 [ISTA RegFox](./ISTA-RegFox)  
Управление реестром Windows для **BMW ISTA/Rheingold**.  
Безопасно включайте/выключайте режим программирования, делайте автоматические бэкапы и восстанавливайтесь в любой момент.

> ⚠️ **Важно**: Изменяет реестр Windows. Используйте на свой риск.

#### 2. 🔄 [PSDZData Incremental Updater](./PSDZData-Updater)  
Хватит скачивать **300 ГБ** `psdzdata` при каждом обновлении!  
Этот инструмент сравнивает две версии и создаёт **минимальное обновление** только с изменёнными файлами.

- Проверка через SHA-256
- Работает как .exe — не нужен Python
- Делитесь `.json`-снимками с сообществом!

#### 3. 🦊 [FoxRecalls](./foxrecalls)

- Десктопное приложение (скоро!)
